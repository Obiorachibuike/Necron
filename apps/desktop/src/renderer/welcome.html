Connect your CareerPilot workspace

This app is a native window for a CareerPilot server that already exists. Enter the address you would normally open in a browser. Your account, jobs, documents and interviews stay on that server — the desktop shell never copies them anywhere else.

Workspace address

Use the web app's root address — not the API port. It must serve the sign-in page and /api/v1/health on the same origin.

How do I get a workspace address?
  1. Running it on this computer: start the backend (uvicorn app.main:app --port 8000 in backend/), then the web app (CP_BACKEND_URL=http://127.0.0.1:8000 npm run dev in apps/web/). Connect to http://localhost:3000.
  2. Using a hosted deployment: use the https address of the Next.js web app. It proxies /api/* to the FastAPI backend, so the desktop app has the same first-party cookies as your browser.
  3. If the address works in a browser and you can sign in there, it will work here. If it doesn't, fix that first — the desktop app adds no server-side configuration.
What the desktop app does and doesn't do
  1. It does: native window, system tray, menus, shortcuts, deep links (careerpilot://), download handling, desktop notifications and signed updates.
  2. It doesn't: run the backend, store your password, or send data to anyone except the workspace you enter. No analytics or telemetry are built in.
  3. Sessions live in an isolated cookie store on this device. Signing out clears them for that workspace.
Plain http is for local development. Traffic to a remote http address is not encrypted. Use https for anything reachable from the internet.
